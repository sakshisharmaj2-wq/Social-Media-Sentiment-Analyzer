# Social Media Sentiment Analyzer-

A Machine Learning-based application that analyzes social media text and classifies it into **Positive, Negative, or Neutral** sentiment.
The project uses (TF-IDF for text feature extraction), a trained Scikit-learn machine learning model, and Streamlit to provide an interactive web application.

# Project Objective

The objective of this project is to analyze customer and social media opinions automatically and provide useful insights that can help businesses understand customer feedback.

# Features

- 😊 Positive sentiment detection
- 😞 Negative sentiment detection
- 😐 Neutral sentiment detection
- 📊 Sentiment probability
- 🏢 Business insights
- ✅ Recommended business actions
- 🌐 Interactive Streamlit interface
